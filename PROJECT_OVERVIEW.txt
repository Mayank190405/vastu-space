1. EXECUTIVE SUMMARY & OBJECTIVE
--------------------------------------------------------------------------------
VĀSTU (Namma Space) is an automated spatial computing platform designed to convert
standard smartphone camera captures into metric-accurate, photorealistic 3D digital 
twins with zero manual 3D modeling (no CAD or Blender required). 

The platform features:
1. Standard Operating Procedure (SOP) guided mobile data capture.
2. An automated 9-stage reconstruction pipeline (Structure-from-Motion, dense 
   depth estimation, Poisson surface meshing, texture atlas synthesis).
3. Indoor spatial indexing (semantic POI labeling, room extraction).
4. Obstacle-aware 3D NavMesh A* pathfinding (with ADA wheelchair slope checks).
5. A zero-install WebGL/Three.js interactive web viewer with first-person 
   roaming, floor height constraints, and collision boundaries.
6. Mobile browser live AR camera navigation with 3D directional guidance arrows.

3. END-TO-END DATA WORKFLOW
--------------------------------------------------------------------------------
Step 1: Input Capture
- Standard smartphone captures 4K 30/60fps video + 6-DoF IMU movement.
- Built-in SOP engine ensures 70-80% image overlap, 1.5-2m distance from walls,
  and proper corner anchor sweeps.

Step 2: Automated Reconstruction (Zero CAD / Zero Manual Labor)
- Sharp keyframes extracted; motion-blurred frames filtered out automatically.
- Structure-from-Motion estimates exact camera positions and sparse geometry.
- Multi-view depth maps are computed, merged, and meshed into watertight 3D models.
- Textures are mapped using visibility weighting for photorealistic finish.

Step 3: Spatial Indexing & Navigation
- The floor plane is isolated to extract a 2D/3D Walkable NavMesh.
- Physical obstacles (walls, furniture, fixtures) form collision boundaries.
- Points of Interest (POIs, e.g. "Meeting Room", "Fire Exit") are indexed.
- The 3D A* router computes non-colliding walking trajectories.

Step 4: Zero-Install Client Delivery
- The model loads immediately in modern desktop and mobile browsers.
- Desktop users roam with fluid WASD keys and mouse look constrained to floor height.
- Users can search for rooms and see glowing floor path lines guiding them around walls.
- Mobile users can open the AR camera mode to view live directional arrows overlaid
  on their camera feed.

4. HOW TO RUN THE PROJECT LOCALLY
--------------------------------------------------------------------------------
Prerequisites: Node.js (v18+), Python (3.10+), Docker (optional for databases)

1. Frontend Web App (Zero-Install Viewer & Dashboard):
   $ npm install
   $ npm run dev
   - Web App Gateway: http://localhost:5173
   - Desktop 3D Spatial Viewer (WASD/Orbit/POI): http://localhost:5173/viewer
   - Mobile Live AR Camera Navigation: http://localhost:5173/ar

2. Automated Reconstruction Pipeline (Zero CAD / Fast Turnaround):
   $ python scripts/reconstruct.py --video /path/to/capture.mp4 --output digital_twin_output --deploy
   - Automatically processes video, extracts keyframes, runs SfM & Poisson meshing,
     synthesizes texture atlas, and deploys 3D assets directly to web viewer.

3. Backend Control Plane (FastAPI):
   $ pip install -r requirements-api.txt
   $ uvicorn api.main:app --host 0.0.0.0 --port 8000 --reload
   - API Docs available at: http://localhost:8000/docs
