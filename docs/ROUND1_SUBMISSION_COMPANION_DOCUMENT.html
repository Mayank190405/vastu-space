4. Code Repository & Local Model Reconstruction Setup

GitHub Code Repository: https://github.com/Mayank190405/vastu-space.git
Branch: codex/p0-capture-video-recovery | Test Directory: test_data/

To reconstruct the 3D model locally from scratch on the provided sample data, execute the following commands:

# Step 1: Clone repository
git clone -b codex/p0-capture-video-recovery https://github.com/Mayank190405/vastu-space.git
cd vastu-space

# Step 2: Set up Python environment & dependencies
python3 -m venv venv && source venv/bin/activate
pip install -r backend/workers/requirements.txt

# Step 3: Execute automated 25-stage reconstruction on test dataset
python scripts/reconstruct.py --video test_data/sample_indoor_scan.mp4 --output digital_twin_output --deploy

5. Test Directory & Pre-Captured Sample Data (test_data/)

The repository includes a dedicated test directory (test_data/) containing sample_indoor_scan.mp4 (2.8 MB). This video was captured according to the VĀSTU standard operating procedure (smooth dolly translation, >75% visual overlap, zero motion blur, verified lighting). Running the CLI generates the complete 3D textured mesh, point cloud, and standalone WebGL viewer in digital_twin_output/.
