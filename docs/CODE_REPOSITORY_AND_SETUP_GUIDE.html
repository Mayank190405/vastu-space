2. Quick Setup & Local Model Reconstruction

Follow these 3 steps to set up the environment and reconstruct the 3D model using the sample data:

Step 1: Clone the Repository

git clone -b codex/p0-capture-video-recovery https://github.com/Mayank190405/vastu-space.git
cd vastu-space

Step 2: Create Python Virtual Environment & Install Dependencies

python3 -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
pip install -r backend/workers/requirements.txt

Step 3: Execute Reconstruction on Sample Data

python scripts/reconstruct.py --video test_data/sample_indoor_scan.mp4 --output digital_twin_output --deploy

3. Viewing the Reconstructed Model

  • Direct Standalone WebGL: Double click digital_twin_output/index.html in any modern browser (Chrome, Edge, Safari).
  • Production Cloud Roaming Viewer: https://vastu.krads.co.in/output
  • Full Local Studio: Run npm install && npm run dev and open http://localhost:5173/output.

4. Test Data Directory (test_data/)

The repository includes test_data/sample_indoor_scan.mp4 (2.8 MB), a pre-validated 720p 30fps indoor spatial scan captured according to the VĀSTU standard operating procedure (smooth dolly translation, high visual feature density, and zero motion blur).
